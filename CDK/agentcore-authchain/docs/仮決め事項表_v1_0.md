# 仮決め事項表 v1.0

対象プロンプト：AgentCore認証チェーン検証実装 v1.1（§3 を分離）。本番設計書で未確定の項目を以下の仮決めで進め、検証で得た実測値を「実測結果」列に追記する。仮決めからの逸脱は実装前に要相談（§0-1 規約7）。

| # | 項目 | 仮決め | 根拠 | 実測結果 |
|---|---|---|---|---|
| 1 | AgentCoreへ渡すトークン種別 | **アクセストークン** | OAuth標準（リソースサーバーにはアクセストークン） | |
| 2 | フェデレーション方式 | **SAML** | GenU標準のEntra連携がSAML、日本企業の一般形 | |
| 3 | 注入クレーム名 | `company_code` / `department_code`（トップレベル） | 予約クレーム回避、Cedar側tag名と一致させる契約 | |
| 4 | 生値の受け皿 | `custom:company_raw` / `custom:department_raw`（**mutable必須**） | フェデレーション属性マッピングはmutable必須 | |
| 5 | 正規化未ヒット時 | **クレームを注入しない**（fail-closed）＋Lambda警告ログ | Cedarデフォルト拒否で自然に落ちる | |
