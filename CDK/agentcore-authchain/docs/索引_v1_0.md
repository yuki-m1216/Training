## 2. 文書の分類
### 2-1 計画・台帳（設計判断が載る）

### 2-2 検証ログ（時系列の実測。予想 → 実測 → 解釈）

## 3. 書き方の約束（全文書共通）
- 公開リポジトリのため、GUID／アカウント ID／PoolId／ClientId／メール／UPN／トークン／鍵は `<tenant>`／`<ACCOUNT>`／`<PoolId>`／`<ClientId>`／`<user>@<tenant>…` にマスクする（コミット前に追加行をスキャン）
- 「予想 → 実測 → 解釈」の順で書き、**事実**（公式・実測）と **推定** を分ける。公式に無いものは［推定］を付ける
- ファイル名の `v1_0` は文書のメジャー版。中身の追記は「変更履歴」に日付付きで残す（ファイル名は変えない）
- 図は Mermaid（Claude が作図）。シーケンス図は各 V の完了サマリに置く
